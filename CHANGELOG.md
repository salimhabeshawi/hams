# Changelog

## 1.0.0 - 2026-11-10

- Initial release of the offline local-Wi-Fi voice session app.
- Added speaker and listener flows with generated Hams identities.
- Added headphone-only listener playback and background foreground services.
- Added local encrypted audio transport, Opus support, DSP leveling, and
  diagnostics.
- Added Material 3 Expressive UI, onboarding, settings, help, and about
  screens.
- Added debug/release APK builds for `armeabi-v7a`, `arm64-v8a`, and `x86_64`.
